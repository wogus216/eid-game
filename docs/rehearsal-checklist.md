# 리허설 체크리스트

본행사 진행 전 반드시 체크하세요. 모든 항목을 확인한 후 **Esc 1.5초 홀드로 반드시 초기화**하세요.

## 무대 화면 (데시벨 게임)

- [ ] **프로젝터 출력 확인**
  - 프로젝터 해상도: 1920×1080
  - 무대 앱 전체화면 모드 (F 키)에서 글자나 요소 잘림 없음 확인

- [ ] **절전 차단 이중 확인**
  - 앱이 Wake Lock을 걸지만 브라우저가 거부할 수 있음 → **시스템 설정에서 절전·
    화면보호기를 끄고 전원 어댑터 연결**
  - 게임 진행 중 새로고침을 시도해 이탈 확인창이 뜨는지 (뜨면 정상)

- [ ] **음향 확인** (효과음은 첫 키 입력 전까지 나지 않음)
  - 노트북 출력이 **행사장 음향 시스템**으로 잡혀 있는지 (노트북 스피커 아님)
  - 아무 키나 한 번 눌러 오디오 해제 → 돌림판 틱 소리가 뒷줄까지 들리는 음량인지
  - 데시벨 돌파음이 너무 크지 않은지 (아이들 놀라지 않을 정도)
  - `M` 음소거 토글이 동작하고 좌하단에 표시되는지

- [ ] **Standby 화면 진입**
  - 마스코트, 문구, 우하단 입장 인원 표시 확인

- [ ] **입장 인원 조절**
  - ↑/↓ 키로 입장 인원 증가/감소 동작 확인
  - 최소 입장 인원: 6명 (1차 3명 + 2차 3명)

- [ ] **데시벨 게임 3단계 (시도마다 Enter 2번)** — 문구는 모두 꾸미의 말풍선으로 나옵니다
  - 시도마다 **준비 화면 → (Enter) → 함성**의 두 박자입니다. 준비 화면에서는 게이지가
    바닥에서 미세하게 떨기만 하고 **올라가지 않습니다**. "소리 질러!"를 외치고 관객이
    숨을 들이켠 뒤 Enter를 누르세요.
  - 좌하단 큐 칩이 다음에 무슨 일이 일어나는지 알려줍니다 (`1차 준비` → `1차 함성 시작!`)
  - **1차 시도**: 92dB → "자, 다 같이 소리 질러!" → 종료 후 "오— 좋았어! 근데 더 할 수 있지?"
  - **2차 시도**: 98dB → "이번엔 진짜 크게!" → 종료 후 "앗! 정말 조금 남았어!"
    - 이때부터 **하늘이 절반쯤 노을로 물드는지** 확인
  - **3차 시도**: 104dB → "마지막이야. 준비됐어?" → 돌파 후 "해냈다!! 우리가 해냈어!"
    - **하늘이 완전히 저녁이 되고 주변이 어두워지는지**, 뒷줄에서 답답하지 않은지
    - 돌파 순간 섬광과 함께 낮으로 돌아오는지
  - 진행 중 Enter 연타 시 애니메이션 중복 무시 확인 (busy 플래그 작동)
  - ← 로 준비 화면에 돌아가 같은 시도를 다시 재생할 수 있는지 확인
  - 소리가 커질 때 **나무·꽃이 흔들리고 꾸미가 같이 들썩이는지**

- [ ] **돌림판 추첨 (Roulette)** — 3명씩 두 라운드
  - 보드 제목이 `1차 선물`, 빈칸이 3개인지 확인
  - Enter 3번으로 1차 3명 추첨
  - 3명이 찬 뒤 Enter는 **추첨하지 않고** 2차로 넘어감 (보드가 비고 제목이 `2차 선물`)
    - **이 사이에 1차 선물을 전달하세요**
  - Enter 3번으로 2차 3명 추첨. 1차 당첨 번호가 다시 나오지 않는지 확인
  - 우하단 `다시 뽑기` 버튼으로 **현재 라운드의 마지막 당첨자만** 재추첨되는지 확인
    - 라운드를 넘긴 직후에는 버튼이 보이지 않아야 정상 (이전 라운드는 보호됨)
    - 버튼을 누른 뒤 Enter가 다음 추첨으로 정상 동작하는지 확인
  - R 키로도 같은 재추첨이 되는지 확인

- [ ] **결과 화면 (Result)**
  - `1차 선물` 3장 + `2차 선물` 3장, 총 6장이 잘리지 않고 표시되는지 확인
  - 사진 촬영 각도가 불편하지 않은지 확인

- [ ] **상태 저장 및 복구**
  - 게임 진행 중 임의로 새로고침 (F5 또는 Cmd+R)
  - 새로고침 후 같은 지점(씬)으로 복구되는지 확인

- [ ] **초기화 확인**
  - Esc 키를 1.5초 이상 홀드
  - "초기화하려면 Esc를 계속 누르세요…" 메시지 표시
  - 초기화 후 Standby 상태로 돌아감 확인
  - **리허설 종료 후 반드시 실행**

- [ ] **이전 단계 복귀**
  - ← 키로 이전 단계로 돌아가기 동작 확인

## 참가자 폰 페이지

- [ ] **iOS Safari에서 테스트**
  - 실제 iOS 기기 (iPad/iPhone)에서 `/join.html` 접속
  - 이름 입력 필드 활성화 및 키보드 입력 정상 동작
  - "로그인" 버튼 탭 후 성공 연출 (문구 + 애니메이션) 확인

- [ ] **Android Chrome에서 테스트**
  - 실제 Android 기기에서 `/join.html` 접속
  - 이름 입력 필드 활성화 및 키보드 입력 정상 동작
  - "로그인" 버튼 탭 후 성공 연출 확인
