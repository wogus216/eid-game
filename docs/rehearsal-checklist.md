# 리허설 체크리스트

본행사 진행 전 반드시 체크하세요. 모든 항목을 확인한 후 **Esc 1.5초 홀드로 반드시 초기화**하세요.

## 무대 화면 (데시벨 게임)

- [ ] **프로젝터 출력 확인**
  - 프로젝터 해상도: 1920×1080
  - 무대 앱 전체화면 모드 (F 키)에서 글자나 요소 잘림 없음 확인

- [ ] **Standby 화면 진입**
  - 마스코트, 문구, 우하단 입장 인원 표시 확인

- [ ] **입장 인원 조절**
  - ↑/↓ 키로 입장 인원 증가/감소 동작 확인
  - 최소 입장 인원: 4명 (우승자 수)

- [ ] **데시벨 게임 3단계 (Enter로 진행)**
  - **1차 시도**: 92dB → 진행 중 "다 같이 소리 질러!", 종료 후 "아깝다!" 표시 및 애니메이션 확인
  - **2차 시도**: 98dB → 진행 중 "다 같이 소리 질러!", 종료 후 "아깝다!" 표시 및 애니메이션 확인
  - **3차 시도**: 104dB → 진행 중 "마지막 기회!", 종료 후 "목표 돌파!!" 표시 및 성공 애니메이션 확인
  - 진행 중 Enter 연타 시 애니메이션 중복 무시 확인 (busy 플래그 작동)

- [ ] **돌림판 추첨 (Roulette)**
  - 4명의 우승자 추첨 애니메이션 재생 확인
  - R 키로 마지막 우승자만 재추첨 동작 확인
  - 재추첨 시 같은 번호 재등장 없음 확인

- [ ] **결과 화면 (Result)**
  - 4명의 우승자 카드 표시 확인
  - 사진 촬영 각도가 불편하지 않은지 확인

- [ ] **상태 저장 및 복구**
  - 게임 진행 중 임의로 새로고침 (F5 또는 Cmd+R)
  - 새로고침 후 같은 지점(씬)으로 복구되는지 확인

- [ ] **초기화 확인**
  - Esc 키를 1.5초 이상 홀드
  - "초기화하려면 Esc를 계속 누르세요…" 메시지 표시
  - 초기화 후 Standby 상태로 돌아감 확인
  - **리허설 종료 후 반드시 실행**

- [ ] **이전 단계 복귀**
  - ← 키로 이전 단계로 돌아가기 동작 확인

## 참가자 폰 페이지

- [ ] **iOS Safari에서 테스트**
  - 실제 iOS 기기 (iPad/iPhone)에서 `/join.html` 접속
  - 이름 입력 필드 활성화 및 키보드 입력 정상 동작
  - "로그인" 버튼 탭 후 성공 연출 (문구 + 애니메이션) 확인

- [ ] **Android Chrome에서 테스트**
  - 실제 Android 기기에서 `/join.html` 접속
  - 이름 입력 필드 활성화 및 키보드 입력 정상 동작
  - "로그인" 버튼 탭 후 성공 연출 확인

## 운영 환경

- [ ] **노트북 전원 관리**
  - 절전 모드 비활성화
  - 화면 보호기 비활성화
  - AC 어댑터(충전기)로 전원 공급 중 (배터리 모드 금지)
